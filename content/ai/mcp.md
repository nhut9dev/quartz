**MCP** stands for Model Context Protocol.

It defines a way for AI applications to connect [[llm|models]] with [[tool-use|tools]], resources, [[system-prompt|prompts]], and external context.

MCP helps separate model clients from specific tool integrations, making capabilities easier to reuse across applications.
