**OWASP Top 10** is a regularly updated list of the most critical security risks facing web applications.

It is published by the Open Worldwide Application Security Project as an awareness document for developers and security teams.

Categories include broken access control, injection, cryptographic failures, and insecure design.

It is a starting point for prioritizing risk, not a complete checklist. Real applications need [[threat-modeling|threat modeling]] for their specific context.

Treat it as a shared vocabulary that helps teams talk about classes of bugs like [[sql-injection|SQL injection]], [[../web/xss|XSS]], and [[ssrf|SSRF]].
