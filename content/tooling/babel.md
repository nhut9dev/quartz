**Babel** transforms JavaScript syntax.

It can [[transpiler|compile]] newer language features, [[jsx|JSX]], and plugin-based syntax into code supported by target environments.

Modern build tools may use alternatives for speed, but Babel remains important because of its ecosystem and transformation flexibility.
