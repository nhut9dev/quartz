---
title: Native app
description: An app installed on a mobile device and built against platform capabilities.
tags:
  - mobile
---

A **native app** is installed on a device and built against mobile platform capabilities. It can use device APIs, app lifecycle events, push notifications, offline storage, and platform UI conventions.

Native apps are distributed through channels like the [[app-store|App Store]] or Google Play, or through enterprise/internal distribution.

React Native builds native apps with React. The UI is described in JavaScript, but the app still ships as an iOS or Android application.

This differs from a [[spa|single-page application]], which runs inside a browser tab and follows web platform rules.
