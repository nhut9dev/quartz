A **stack** is a last-in, first-out data structure. The newest item added is the first item removed.

```txt
push A
push B
pop -> B
```

Stacks are useful for undo history, parsing, browser navigation, backtracking, and function calls. JavaScript's [[../javascript/call-stack|call stack]] follows the same last-in, first-out idea.

Typical operations are `push`, `pop`, and `peek`.
