**iOS** is Apple's mobile operating system for iPhone. iPad apps run on iPadOS, which shares much of the same development model.

iOS apps are built with Apple tooling, signed with Apple certificates, and distributed through the App Store, TestFlight, enterprise distribution, or local development builds.

React Native apps targeting iOS still need native iOS project configuration for permissions, capabilities, dependencies, icons, launch screens, and signing.

iOS platform details often show up around safe areas, push notifications, background modes, deep links, and privacy permission prompts.
