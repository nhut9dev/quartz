The Node.js `crypto` module provides cryptographic primitives.

Common uses include secure random tokens, HMAC signatures, hashing, encryption, and key handling.

Use high-level, reviewed libraries for application security when possible. Cryptography is easy to misuse even when the primitive is correct.

For passwords, use dedicated password hashing algorithms rather than plain hashes.
