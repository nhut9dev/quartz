**Virus scanning** checks uploaded files for known malware or suspicious content.

It is important for documents, archives, executables, user-shared attachments, and enterprise workflows.

A common pattern is to upload into a quarantine state, scan asynchronously, then mark the file as clean or rejected.

Scanning reduces risk, but it is not perfect. Keep access control, file type restrictions, and safe serving behavior in place.
