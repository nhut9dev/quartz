A **documentation culture** is the set of shared habits that keep written knowledge useful, discoverable, and current.

Docs decay when nobody owns them, so healthy teams treat updates as part of finishing work rather than an afterthought. Stale documentation is often worse than none, because it misleads with false confidence.

Discoverability matters as much as accuracy: a correct doc nobody can find does not help. Consistent locations, search, and cross-links turn scattered notes into a navigable garden.

The strongest signal of a documentation culture is that writing things down is the default, not a chore reserved for big launches.

It rests on [[../career/technical-writing|technical writing]] and feeds artifacts like [[rfc|RFCs]], [[architecture-decision-record|ADRs]], and [[../observability/runbook|runbooks]].
