**GitHub Actions** runs automation workflows from a repository. Workflows are usually stored as YAML files under `.github/workflows`.

Common workflows run tests on pull requests, build artifacts on pushes, publish packages, or deploy an application.

GitHub Actions is one implementation of [[ci|continuous integration]]. The underlying ideas apply to other CI systems too.
