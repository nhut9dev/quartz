**React Native CLI** is the lower-level workflow for creating and running React Native apps with direct access to the native iOS and Android projects.

It gives you `ios/` and `android/` folders where native configuration, dependencies, build settings, and platform code live.

This is useful when a project needs custom native modules, unusual build settings, or close control over platform integration.

Compared with [[expo|Expo]], React Native CLI gives more direct native control but usually requires more platform setup and maintenance.
