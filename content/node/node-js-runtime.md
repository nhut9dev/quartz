The **Node.js runtime** runs JavaScript outside the browser. It provides access to operating system APIs such as files, networking, processes, and streams.

Node is commonly used for HTTP servers, CLIs, build tools, background jobs, and scripts. Frameworks like [[../express/introduction|Express]] build on top of Node's lower-level HTTP features.

Node shares the JavaScript language with browsers, but not every browser API exists in Node, and not every Node API exists in browsers.
