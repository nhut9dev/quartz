title: iframe
description: An HTML element that embeds another browsing context inside the page.
tags:

---

An `iframe` embeds another page inside the current page.

Common uses include maps, videos, payment widgets, previews, and third-party tools.

Iframes create isolation boundaries, but they also add performance, security, and accessibility concerns.

Use attributes such as `title`, `sandbox`, `allow`, and explicit dimensions to make iframes safer and more understandable.
