---
title: Fetch, pull, and push
description: The everyday Git commands for exchanging commits with a remote.
tags:
  - git
---

**Fetch**, **pull**, and **push** move commit information between a local repository and a [[remote|remote]].

`git fetch` downloads remote changes without changing the current branch.

`git pull` fetches and then integrates the remote branch into the current branch, usually by [[merge]] or [[rebase]].

`git push` uploads local commits to a remote branch.
