A **pull request** is a proposed set of changes that someone wants to [[merge]] into another [[branch]]. It usually includes a diff, discussion, [[ci|automated checks]], and review comments.

Pull requests help teams review code, run tests, discuss tradeoffs, and document why a change was made.

A good pull request is focused. It should be small enough for reviewers to understand the risk and test the behavior.
