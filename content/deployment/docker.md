**Docker** packages an application and its runtime dependencies into a container image. A container runs from that image with an isolated filesystem and process environment.

Docker helps make development, CI, and production more consistent. A backend app can depend on the same Node version, system packages, and startup command across environments.

The fuller Docker map lives in [[../docker/|Docker]] and covers [[../docker/dockerfile|Dockerfile]], [[../docker/docker-image|Docker image]], [[../docker/docker-container|Docker container]], [[../docker/docker-compose|Docker Compose]], [[../docker/docker-volume|volumes]], and [[../docker/docker-network|networks]].

Docker is useful, but it does not replace understanding configuration, networking, storage, and deployment platform behavior.
