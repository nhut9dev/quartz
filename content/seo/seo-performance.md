**SEO performance** is the part of SEO concerned with fast, stable, user-friendly page loading.

Search engines want pages that users can load and use. Performance signals include [[../web/core-web-vitals|Core Web Vitals]], mobile usability, server latency, render-blocking resources, image weight, layout stability, and whether the main content appears quickly.

Performance SEO overlaps with [[../frontend-performance/critical-rendering-path|critical rendering path]], [[../frontend-performance/image-optimization|image optimization]], [[../web/caching|caching]], [[../web/compression|compression]], and [[../web/lazy-loading|lazy loading]].

Do not optimize scores while hurting the page. Lazy loading the main image, hiding content behind interaction, or removing useful content for speed can make search and user outcomes worse.
