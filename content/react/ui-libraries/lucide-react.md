**Lucide React** provides SVG icon components for React.

```jsx
import { Search } from "lucide-react"

function SearchButton() {
  return (
    <button>
      <Search size={16} />
      Search
    </button>
  )
}
```

Use icon components for actions, navigation, empty states, and compact controls. Keep icons paired with accessible labels when the meaning is not obvious.
