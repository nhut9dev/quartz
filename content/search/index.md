Search is about returning the most relevant results, not just exact matches. These notes cover the techniques that make search fast and useful, from classic keyword ranking to semantic vectors and the engines that run them in production.

- [[full-text-search|Full-text search]] — relevance ranking over text with inverted indexes
- [[vector-search|Vector search]] — semantic search using embeddings and nearest neighbors
- [[elasticsearch|Elasticsearch]] — the distributed search engine built on Lucene
