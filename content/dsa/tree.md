A **tree** is a hierarchical data structure made of nodes. Each node can have children, and the top node is called the root.

```txt
root
├─ child
└─ child
```

Trees model nested data: file systems, comments, menus, HTML, syntax trees, and organization charts. The browser [[../dom/dom-tree|DOM tree]] is a practical example.

Common tree algorithms use [[depth-first-search|depth-first search]], [[breadth-first-search|breadth-first search]], or [[recursion-algorithm|recursion]].
