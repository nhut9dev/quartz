---
title: Dialog element
description: The native HTML element for dialogs and modal interactions.
tags:
  - html
  - accessibility
---

The `dialog` element represents a dialog box or modal.

```html
<dialog>
  <p>Confirm action?</p>
</dialog>
```

The `showModal()` method opens it as a modal and asks the browser to handle some focus and backdrop behavior.

Native dialog behavior helps, but complex dialogs still need careful labels, focus management, keyboard behavior, and close controls.
