**TanStack Form** is a headless form library for managing form state, validation, and submission. It does not impose UI components.

It fits teams that want explicit form state and strong TypeScript support, especially when already using TanStack libraries like [[../data-fetching/tanstack-query|TanStack Query]] or [[../routing/tanstack-router|TanStack Router]].

Use it when form behavior is complex enough that hand-written state becomes noisy, but you still want full control over markup and styling.
