---
title: BEM
description: A CSS naming convention based on blocks, elements, and modifiers.
tags:
  - css
---

**BEM** stands for block, element, modifier.

```css
.card {}
.card__title {}
.card--featured {}
```

It makes class names explicit and reduces accidental selector collisions.

BEM is most useful in plain CSS or large CSS codebases without stronger scoping tools.
