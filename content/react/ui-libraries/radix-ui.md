**Radix UI** provides headless accessible primitives for components like dialogs, dropdowns, popovers, tabs, tooltips, and menus.

Headless means Radix handles behavior and accessibility, while you control styling.

Use Radix when you want custom design but do not want to rebuild hard interaction details like focus trapping, keyboard navigation, ARIA attributes, and escape-key behavior.

[[shadcn-ui|shadcn/ui]] is built on Radix primitives for many components.
