**On-page SEO** is optimizing an individual page so its purpose, relevance, and structure are clear to search engines and users.

### How it works

Search engines use visible content and page metadata to infer what a page is about. A strong page has one clear search intent, a descriptive [[title-tag|title tag]], useful [[meta-description|meta description]], semantic headings, readable body content, descriptive links, and media with relevant alt text.

The page should answer the query better than competing pages, not merely repeat keywords. Good structure helps crawlers and readers: headings outline the topic, paragraphs make claims clear, and [[internal-linking|internal links]] connect the page to related context.

### When to use

Use on-page SEO whenever publishing a public page that should earn search traffic: landing pages, articles, docs, product pages, category pages, and comparison pages.

### Trade-offs

Clear keyword targeting helps relevance, but keyword stuffing harms readability and trust. A page should sound like it was written for a human with a specific job to do.

### Pitfalls

Avoid duplicate titles, vague headings, thin content, orphan pages, image-only text, generic anchor text like "click here", and pages that target several unrelated intents at once.
