---
title: details and summary
description: Native HTML elements for expandable disclosure content.
tags:
  - html
---

`details` and `summary` create a native expandable disclosure widget.

```html
<details>
  <summary>More options</summary>
  <p>Hidden content appears here.</p>
</details>
```

They are useful for FAQs, optional details, advanced settings, and progressive disclosure.

Use them when the interaction is simple. Complex accordion behavior may need custom state and accessibility handling.
