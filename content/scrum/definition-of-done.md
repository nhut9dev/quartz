The **Definition of Done** is the shared quality standard an [[increment|Increment]] must meet to be considered done.

It might include code review, tests passing, documentation updated, accessibility checked, monitoring added, or deployment readiness.

The Definition of Done creates transparency. Everyone can tell whether work is actually complete or only partially finished.

If work does not meet the Definition of Done, it should not be counted as part of the done increment.
