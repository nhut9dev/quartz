title: Branch
description: A movable name for a line of Git history.
tags:
  - git
---

A **branch** is a movable name that points to a [[commit]]. Developers use branches to work on changes without immediately changing the main line of history.

```bash
git switch -c add-login-form
```

Branches are cheap in Git. A branch can represent a feature, bug fix, experiment, release, or integration line.
