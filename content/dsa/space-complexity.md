**Space complexity** describes how much extra memory an algorithm uses as input size grows.

An algorithm that only tracks a few variables is often `O(1)` space. An algorithm that builds a new array the same size as the input is usually `O(n)` space.

Space complexity matters when inputs are large, memory is limited, or a faster algorithm needs extra storage such as a [[hash-table|hash table]].
