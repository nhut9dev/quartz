A **design system** gives a product team shared UI building blocks and decisions.

It can include colors, typography, spacing, icons, [[component-composition|components]], accessibility rules, content patterns, and implementation guidelines.

Design systems reduce repeated decisions and make interfaces more consistent. They are most valuable when teams reuse the same patterns across many screens.

A design system is not only a component library, and each reusable component still needs a clear [[component-boundary|component boundary]]. It also explains when to use each pattern and what tradeoffs the product has already chosen.
