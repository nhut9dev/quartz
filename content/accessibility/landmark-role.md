---
title: Landmark role
description: A semantic page region that helps assistive technology users navigate quickly.
tags:
  - accessibility
  - html
---

A **landmark** is a major page region such as header, navigation, main content, aside, or footer.

Native HTML elements like `header`, `nav`, `main`, `aside`, and `footer` usually provide landmark semantics without extra ARIA.

Landmarks help [[screen-reader|screen reader]] users jump through page structure instead of tabbing through every control.

Prefer [[semantic-html|semantic HTML]] first. Add [[aria|ARIA]] landmark roles only when native elements are not enough.
