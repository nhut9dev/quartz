title: Metadata API
description: Next.js APIs for defining document metadata such as title, description, and Open Graph data.
tags:

  - seo
---

The **Metadata API** defines page metadata, rendered as [[meta-tags|meta tags]], in Next.js App Router routes.

It can set titles, descriptions, canonical URLs, Open Graph data, icons, robots settings, and more, which together drive [[seo|SEO]] and link previews.

Metadata can be static or generated from route params and data.
