---
title: Meta element
description: An HTML element for document metadata such as charset, viewport, and page description.
tags:
  - html
---

The `meta` element provides metadata about an HTML document.

Common metadata includes character encoding, viewport behavior, page description, and social preview data.

```html
<meta charset="utf-8" />
<meta name="viewport" content="width=device-width, initial-scale=1" />
```

Metadata affects rendering, SEO, sharing previews, and browser behavior, but it does not render visible page content by itself.
