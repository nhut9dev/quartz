The **filesystem hierarchy** gives Linux systems a predictable directory layout.

Common paths include `/etc` for configuration, `/var` for changing runtime data, `/home` for user files, `/tmp` for temporary files, `/usr` for installed programs and libraries, and `/bin` or `/sbin` for essential commands.

Knowing the layout helps debugging: logs, service files, config, binaries, and user data usually live in different places by convention.
