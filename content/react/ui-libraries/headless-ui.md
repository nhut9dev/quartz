**Headless UI** provides unstyled accessible components such as dialogs, menus, listboxes, switches, and tabs.

It pairs naturally with [[tailwind-css|Tailwind CSS]], but the components are not limited to Tailwind.

Use it when you want accessible behavior without adopting a full visual component kit.
