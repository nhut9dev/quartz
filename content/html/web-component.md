A **web component** is a reusable browser-native component built from custom elements, shadow DOM, and templates.

Web components can work across frameworks because the browser understands them as elements.

They are useful for shared UI across different stacks, embeddable widgets, and design system primitives.

The tradeoff is that framework integration, styling boundaries, and server rendering can require extra care.
