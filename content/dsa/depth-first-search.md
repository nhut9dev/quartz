**Depth-first search** (DFS) explores a [[graph|graph]] or [[tree|tree]] by going deep along one path before backtracking.

DFS can be implemented with [[recursion-algorithm|recursion]] or an explicit [[stack|stack]].

DFS is useful for tree traversal, connected components, cycle detection, topological sorting, and backtracking problems.
