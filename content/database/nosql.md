---
title: NoSQL
description: A broad category of non-relational database models such as document and key-value stores.
tags:
  - database
---

**NoSQL** describes databases that do not primarily use the relational table model.

Common types include document stores, key-value stores, wide-column stores, and graph databases.

NoSQL systems often optimize for flexible schemas, scale patterns, or specific access models.

The right database depends on query shape, consistency needs, operations, and how the application changes over time.
