**Prettier** formats code automatically.

It reduces style debates by applying a consistent format across the project.

Prettier focuses on formatting, not code correctness. Pair it with [[eslint|ESLint]] for linting and often run it on staged files through [[../repo-quality/lint-staged|lint-staged]].
