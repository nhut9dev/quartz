**Design scale** is a limited set of reusable values for size, spacing, type, radius, and elevation.

Scales reduce arbitrary decisions. Instead of choosing any value, a team chooses from a small ladder that creates rhythm across components and pages.

Common scales include spacing, type size, radius, shadow, z-index, and icon size. When these values need to be shared between design and code, they often become [[../css/design-token|design tokens]].

A scale should be useful, not decorative. Too many steps recreate the same inconsistency under official names.
