**Typography** is the design of text so content is readable, scannable, and visually ordered.

### How it works

Typography combines typeface, size, weight, line height, line length, spacing, and contrast. In UI, the goal is usually not expressive lettering; it is making labels, headings, body copy, numbers, and controls easy to scan under real usage.

A type scale creates predictable jumps between text roles. Body text needs enough line height for reading, compact UI text needs tighter rhythm, and headings need hierarchy without becoming so large that they dominate the task.

### When to use

Use typography to clarify information architecture: page title, section heading, field label, helper text, table value, and error message should not all compete at the same strength. Pair it with [[visual-hierarchy|visual hierarchy]] and [[spacing|spacing]].

### Trade-offs

More type styles can make individual moments expressive, but they make systems harder to maintain. Fewer styles improve consistency, but they need enough contrast in size, weight, and color to support real content.

### Pitfalls

Avoid using color or font weight as the only hierarchy. Long text, localization, dense tables, mobile widths, and user zoom can expose weak typographic decisions quickly.
