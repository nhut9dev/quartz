An **OpenAPI contract** describes an HTTP API in a machine-readable format.

It can document paths, methods, parameters, request bodies, response bodies, status codes, authentication, and reusable schemas.

Teams use OpenAPI for documentation, generated clients, mock servers, contract tests, and review of API changes.

An OpenAPI contract is most useful when it stays close to the real implementation and is checked by [[../testing/contract-testing|contract testing]] or CI.
