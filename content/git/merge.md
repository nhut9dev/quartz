---
title: Merge
description: Combining the history from one Git branch into another.
tags:
  - git
---

A **merge** combines changes from one [[branch]] into another. If Git can combine the changes automatically, it creates a merge result. If the same lines changed differently, a [[merge-conflict|merge conflict]] must be resolved.

Merging preserves the fact that work happened on separate branches. This can make collaboration history easier to follow in repositories where many people work in parallel.
