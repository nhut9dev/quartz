`next/image` is Next.js's image component.

It helps with responsive sizing, [[lazy-loading|lazy loading]], [[image-optimization|format optimization]], and layout stability, all of which improve [[core-web-vitals|Core Web Vitals]].

Use it for product images, content images, avatars, and hero media when the image source fits the project's image configuration.
