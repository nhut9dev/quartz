**Meta description** is a short page summary that can appear as the search result snippet.

It is not a direct ranking lever in the same way content relevance is, but it affects whether a searcher understands and clicks the result. A useful description states what the page offers in plain language.

Each important page should have a unique description that matches its content. It works with the [[title-tag|title tag]] and broader [[../web/meta-tags|meta tags]].

Avoid stuffing keywords, repeating the title exactly, or using a generic site-wide description on every page.
