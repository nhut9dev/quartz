title: System prompt
description: High-priority model instructions that define behavior, role, and constraints.
tags:

---

A **system prompt** gives high-priority instructions to a [[llm|model]].

It can define role, tone, safety constraints, [[tool-use|tool-use policy]], output format, and domain assumptions.

System prompts are not a security boundary by themselves. Applications still need validation and authorization around tools and data.
