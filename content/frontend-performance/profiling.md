---
title: Profiling
description: Measuring where code spends time or memory before optimizing it.
tags:
  - performance
---

**Profiling** records runtime behavior so you can find the real bottleneck.

Frontend profiling may inspect JavaScript execution, rendering, network waterfalls, memory allocation, and [[re-render|React component updates]].

Profile before optimizing. Guessing often improves code that was not the problem.
