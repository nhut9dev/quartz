---
title: Navigation lifecycle
description: The browser sequence of leaving one document and loading another.
tags:

  - web
---

The **navigation lifecycle** covers what happens when the browser moves to a new page or document.

It includes URL resolution, network request, response processing, document parsing, script execution, rendering, and page lifecycle events.

Modern browser behavior is affected by caches, redirects, service workers, security policies, and [[bfcache|bfcache]]. Understanding this lifecycle helps debug slow loads and lost state.
