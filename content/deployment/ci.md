---
title: Continuous integration
description: Automatically checking code changes before they are merged or released.
tags:
  - deployment
  - testing
---

**Continuous integration** (CI) automatically checks code changes with tasks such as install, lint, typecheck, test, and build.

CI gives a team fast feedback before a change is merged or deployed. It is most useful when checks are deterministic and close to the commands developers run locally.

CI does not prove a change is correct, but it catches many common regressions before they reach users.
