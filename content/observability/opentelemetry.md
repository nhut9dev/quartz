**OpenTelemetry** provides APIs, SDKs, and conventions for collecting telemetry data.

It helps instrument applications without tying all code to one monitoring vendor.

OpenTelemetry is commonly used for [[tracing|traces]], [[metrics|metrics]], logs, context propagation, and exporters.
