title: Semantic structure
description: Using HTML elements such as header, nav, main, section, and footer to describe page regions.

**Semantic structure** uses HTML elements that describe the purpose of page regions.

Typical page structure includes `header`, `nav`, `main`, `section`, `article`, `aside`, and `footer`.

This structure helps browsers, search engines, and assistive technologies understand the document.

Use semantic elements for meaning, not styling. CSS can style any element, but semantics should match the content.
