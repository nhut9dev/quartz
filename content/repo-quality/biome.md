**Biome** is a fast formatter and linter for JavaScript, TypeScript, JSON, and related web files.

It is often considered when a team wants one tool for formatting and many common lint rules. In some projects it can replace [[../tooling/prettier|Prettier]] and part of [[../tooling/eslint|ESLint]].

Use Biome when speed and simple configuration matter more than the full ESLint plugin ecosystem.

The trade-off is coverage. ESLint still has broader plugin support for framework-specific, type-aware, and organization-specific rules.
